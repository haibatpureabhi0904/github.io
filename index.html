                    ATM Interface Simulation                     GitHub                

               
Aug 2026
               

Date: August 2026

               

Tech Stack: STM32, C Programming, Proteus VSM

               

Details: You designed and simulated a bare-metal STM32 Automated Teller Machine (ATM) controller. The core of this project was implementing a robust Finite State Machine (FSM) architecture to manage complex multi-peripheral interfacing. The hardware integrated into the simulation included an ADC joystick, a 4x4 matrix keypad, an 8-bit LCD, and multiplexed 7-segment displays. The entire functionality and logic were successfully validated using Proteus VSM.
